How it works

Every scoring shot becomes a goal with the same chance, the league's goal conversion rate for the season. The rest are behinds. Because a goal is worth six and a behind one, a team with S scoring shots and G goals scores S + 5G points.

expected score = S × (1 + 5p)
win chance = every pair of possible scores, added up exactly

Nothing is simulated. The model works through every possible number of goals for both teams and adds up how often each side finishes in front.

Where it's wrong

  • Every shot gets the same chance. A set shot from 15 metres and a snap from the boundary are treated alike, because shot-location data isn't public.
  • Rushed behinds count as scoring shots, and shots that miss everything don't count at all.
  • It ignores the state of the game. A side 40 points up can stop chasing shots.
